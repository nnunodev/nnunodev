### Featured

**[soundaudit](https://github.com/nnunodev/soundaudit)** — music library health scanner and metadata repair tool.

Scans large FLAC/MP3 collections, fingerprints audio, resolves canonical tags against MusicBrainz, detects fake-FLAC transcodes and duplicate files, then writes corrections back with backups. Interactive terminal UI plus a scriptable CLI with JSON/CSV/Markdown export.

`Python` · `Typer` · `Rich` · `SQLite` · `AcoustID` · `MusicBrainz`

```bash
pip install soundaudit
```

Published on PyPI, MIT licensed.
