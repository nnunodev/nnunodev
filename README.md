**[1UpLoot](https://github.com/nnunodev/1UpLoot)** ![Full Stack](https://img.shields.io/badge/Full_Stack_Project-0f766e?style=flat-square)

`Python` `Flask` `MongoDB` `HTML/CSS` `Materialize` `jQuery`

A full-stack web application developed during my Code Institute course, designed for video game collectors to organise, manage and track their collections.

Built with Flask and MongoDB, using PyMongo for database operations, Flask-Bcrypt for password hashing and Materialize for the user interface. Originally deployed using Heroku.
